# AURA / FREQUENCY

An independent portable-speaker concept and interactive motion study. This second AURA experience lives separately from [the original website](https://wang-wang9q.github.io/aura-sound-unbound/).

## Experience

- Original WebGL orbital light field, responding to the pointer.
- Cinematic typography, floating product, rotating light tracks and magnetic controls.
- GSAP scroll-driven product structure sequence with three chapters.
- 3D-projected particle sphere, torus and wave with continuous topology morphs.
- Pointer orbit, particle repulsion and tap-triggered ripple pulses.
- Original synthesized Web Audio soundscapes. The particle amplitude reads real post-volume RMS from an AnalyserNode.
- Scroll-revealed full-bleed landscape, whole-stage color selection and downloadable personalized visual card.
- Responsive layouts, reduced-motion preference support, optional light-motion control and background/offscreen animation suspension.

## Run

Serve this directory with any static HTTP server. No build or remote asset dependency is required.
